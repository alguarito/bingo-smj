# 🎱 Bingo Institucional — I.E. Sor María Juliana

Aplicación web para un **bingo institucional de 75 balotas (B-I-N-G-O)** con capacidad para **1000 tablas únicas**. Funciona en el navegador, sin instalación.

**▶️ App en vivo:** https://alguarito.github.io/bingo-smj/

## Funciones
- **🖨️ Generador de tablas** — 1000 cartones únicos con folio (0001–1000), en cuarto de carta (4 por hoja), listos para imprimir o guardar en PDF (blanco y negro económico). Encabezado del evento editable.
- **🎱 Visor / Balotera digital** — balota animada con voz y efectos, tablero de salidos, temporizador automático, **patrón ganador configurable** (matriz 5×5) y **verificador por folio**.

## Uso rápido
- Abre la **app en vivo** (enlace de arriba), o el archivo `index.html` localmente.
- Para usar/compartir **sin internet**: el archivo `Bingo SMJ - App (1 archivo).html` lleva todo incrustado (un solo archivo).

## Desarrollo
- Sitio estático: **HTML + CSS + JS**, sin dependencias.
- `python3 bundle.py` regenera el archivo único autocontenido.
- **Despliegue automático**: cada `push` a `main` publica la app en GitHub Pages.
